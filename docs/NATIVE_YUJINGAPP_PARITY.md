# 原生 App 与 yujingapp 功能对齐清单

`G:\yujingapp` 是功能验收基准。原生实现可以重做交互与视觉，但不能删减业务能力。

## P0：账号与紧急救援

| yujingapp 能力 | 原生状态 | 验收标准 |
| --- | --- | --- |
| 手机号 + 6 位短信验证码注册/登录 | 已实现并启用，待真机号码实测 | 支持国际区号、60 秒重发、验证码校验、创建资料与邀请码关系 |
| 邮箱密码注册/登录 | 已实现 | 注册必须发送确认邮件；未确认不能登录；支持重新发送 |
| 忘记密码 | 已实现恢复邮件和账号内改密，待恢复链接真机回归 | 发送恢复邮件并可设置新密码 |
| 用户协议、隐私政策确认 | 已实现原生正文页与注册确认 | 未同意不能注册，可查看完整正文 |
| SOS 长按触发 | 已实现基础闭环 | 上传位置、创建求救记录、触达家人/救援人、返回求救编号 |
| SOS 历史、取消、解除与升级 | 已实现原生操作与 Realtime 刷新，待线上函数回归 | 可查看状态时间线，并调用 sos-service 对应动作 |
| 紧急资料 | 已实现完整字段；SOS医疗快照待函数重新部署 | 姓名、血型、疾病、过敏、用药、紧急联系人可编辑并被 SOS 使用 |
